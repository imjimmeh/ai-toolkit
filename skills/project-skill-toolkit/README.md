# Project skill toolkit

This directory contains shared reference material used by:

- `bootstrap-brownfield-project`
- `maintain-project-skills`

It is not intended to be selected directly as a normal project skill.

The operational skills reference these files to avoid duplicating:

- evidence rules;
- confidence rules;
- skill-candidate scoring;
- schemas;
- subagent prompts;
- skill templates;
- validation requirements.

Repositories may extend these references with local conventions, but should avoid
copying and diverging them across the bootstrap and maintenance skills.
